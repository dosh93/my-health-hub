Privacy policy

Effective November 6, 2026. Project operator: GitHub user dosh93.

Scope and purpose

This policy describes the current personal, local prototype. It is intended to retrieve and display the owner's own Garmin and Oura records with source labels. It is not currently offered to other users. This policy must be updated before public onboarding or any change to data handling.

Device and account data

The prototype retrieves available workout, activity, sleep and wellness records from connected services. Oura access, once implemented, will use the permissions granted during authorization; these may include heart rate, readiness, oxygen saturation, stress, tags, sessions, heart-health metrics, profile and ring information. Not every metric is available for every device.

Downloaded records are stored locally on the owner's Mac. The prototype does not upload them to this website or its public source repository. Any copies the owner chooses to share with development or support tools are subject to those tools' policies.

Credentials

The current Garmin export scripts use credentials and access tokens in process memory without saving them to disk. Oura authorization and credential storage are still being developed. Credentials must never be committed to the public repository.

Retention and control

The owner controls local exports and can delete them from their device and backups. Access can be revoked through the relevant service's account settings. Revoking access does not delete previously downloaded files. There is no hosted account or hosted health-data database to delete.

This website

This informational website is hosted by GitHub Pages. It contains no health-data upload form, advertising, or project-added analytics or cookies. GitHub may process technical request information, such as IP addresses, under its privacy statement. Garmin and Oura process data under their own policies.

Contact

Contact the operator through the project issue tracker for general questions. Do not post credentials or personal health records in public issues.
